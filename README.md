# R.R. Patel Overseas Staff Portal

A simple attendance management web app for staff and admin access.

## Features
- Admin login and setup screen
- Employee login using employee ID and password
- Attendance check-in and check-out logs
- Admin dashboard to view all attendance records
- CSV export for attendance data
- Logo upload shared between staff app and admin panel

## How to run
Open `index.html` in a browser for the employee portal and `admin.html` for the admin portal.

## Notes
This project is a front-end demo using browser `localStorage`. For production use, move the data layer to a secure backend/database.
